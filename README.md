 * Project Goal: To secure UGX 850,000 in micro-donations to fund physical farm inputs (seeds, organic manure, hand tools, and basic irrigation) needed to plant 1 acre (~500 planting stations) of Bale Sweet Cream pumpkins.
 * Core Pitch: It frames pumpkin farming as a high-yield, low-input solution for sustainable agricultural income, assuring donors that 100% of their contributions go directly to physical supplies.

   * UGX 40,000: Organic Soil Nutrition (5 bags of manure)
   * UGX 100,000: Tools & Irrigation Kit (1/4 acre coverage)
   * UGX 250,000: Quarter-Acre Sponsor (125 stations fully funded)
 * Trust & Conversion Mechanism:
   * Features a visual progress bar (showing UGX 210,000 raised so far) to create momentum.
